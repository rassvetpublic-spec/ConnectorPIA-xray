# ConnectorPIA-xray

Исследовательский и инженерный репозиторий проекта ConnectorPIA-xray.

> Bootstrap: Issue #1. Этот файл — единственный допустимый initial direct commit, необходимый для рождения `main` в изначально пустом репозитории.

## Рабочий процесс

После bootstrap любые изменения выполняются только по цепочке:

`Issue -> fresh branch -> implementation -> tests/validation -> PR -> exact-head CI -> independent QA -> merge -> post-merge main check`

Канонические правила проекта находятся в `AGENTS.md` и `.agent/rules/`.

## Статус

Репозиторий находится на этапе первичной инициализации. Предметная архитектура и импорт локальных материалов из `outputs` должны оформляться отдельными Issues после завершения governance bootstrap.
